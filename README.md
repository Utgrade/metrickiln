# MetricKiln landing page

This folder is ready to publish with GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL_HERE` with the email address you want customers to use.
3. Keep `assets/pmo-control-center-executive-overview.png` in place.

## Suggested GitHub repository

Create a new **public** repository named:

`metrickiln`

Copy the contents of this folder to the repository root.

Then enable GitHub Pages from the repository settings and publish from the `main` branch / root folder.

Expected project-site URL:

`https://utgrade.github.io/metrickiln/`

Use the actual URL shown by GitHub Pages once deployment succeeds.

## Note

The name MetricKiln should remain provisional until trademark/domain checks are complete.
